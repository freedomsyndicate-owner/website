🎬 MOVIE
📋 PANDUAN FS CINEMA
1️⃣ Pilih MOVIE atau SERIES → ketik judul → tekan CARI
2️⃣ Klik poster film yang muncul → langsung play
3️⃣ Server bawaan adalah VidLink. Kalau video tidak jalan, ganti server di dropdown (VidLink → FS Player → VidSrc → VidSrc.cc → 2Embed), langsung pindah, tidak perlu tekan Putar lagi. Atau tekan tombol 🔄 Coba server lain di bawah player
3️⃣b Series baru? Server biasanya cuma punya episode 1 dulu, episode terbaru muncul beberapa hari setelah tayang. Kalau episode 4 belum jalan di semua server, berarti memang belum ada di server mana pun; coba episode 1 dulu.
3️⃣c Judul tidak muncul di hasil cari? Berarti judul itu belum ada stream-nya di server mana pun (mis. film yang belum rilis) — judul seperti itu sengaja tidak ditampilkan supaya tidak mengecewakan.
4️⃣ Muncul tab/popup baru? Itu iklan dari server film lain (bukan FS Player), tutup saja tabnya, video tetap jalan di sini. (Player lain sengaja TIDAK dikunci sandbox, karena VidSrc menolak dimuat di frame bersandbox dan video jadi tidak muncul sama sekali.)
5️⃣ Halaman putih / tidak load? Tekan tombol 🔄 Coba server lain di bawah player (selalu terlihat saat video diputar)
